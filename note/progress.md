# Prompt Diet 프로젝트 작업 현황 및 목표

## 📅 작성일: 2024-05-09

## ✅ 현재 작업 완료 상황
1. **프로젝트 환경 설정**
   - ViewBinding 활성화
   - Material Design 및 ConstraintLayout 기반 UI 환경 구축
2. **리소스 정의**
   - 앱 고유 컬러셋(`header_blue`, `box_grey` 등) 정의
   - 주요 텍스트 리소스(`strings.xml`) 및 메뉴 구조(`bottom_nav_menu.xml`) 작성
3. **레이아웃 구현**
   - 메인 화면: 하단 내비게이션 바 및 프래그먼트 컨테이너 구조
   - 분석 화면: 채팅 텍스트 입력부, 분석 시작 버튼, 결과 표시 영역(ScrollView)
   - 통계 화면: 프로필, 상위 원인, 세부 원인 버튼 대시보드 구조
   - 세부 통계 화면: 상세 로그 데이터를 위한 별도 액티비티 레이아웃
4. **기능 로직 및 분석 엔진**
   - 하단 탭 전환 기능(Analysis <-> Statistics)
   - '세부 추정 원인' 클릭 시 상세 화면 이동 로직 구현
   - **프롬프트 분석 엔진(`PromptAnalyzer`) 구현**: 
     - 중복 단어(Redundancy) 탐지
     - 불필요한 수식어(Verbosity) 탐지
     - 모호한 짧은 요청(Lack of Scope) 탐지
     - 가상 토큰 계산 및 효율성 점수 산정 로직 적용

## 🎯 향후 작업 목표
1. **통계 데이터 시각화**
   - '상위 원인' 영역에 그래프 또는 차트 라이브러리 연동
   - `PromptAnalyzer` 결과를 통계 프래그먼트와 공유하는 로직 (ViewModel 적용 추천)
2. **데이터 저장 및 관리**
   - 분석된 로그를 로컬 DB(Room) 또는 서버에 저장하여 통계 데이터 축적
3. **UI/UX 고도화**
   - 기획안에 맞춰 디자인 디테일(여백, 폰트, 애니메이션) 조정
   - 분석 결과의 시각적 강조 (중복 단어 하이라이트 등)
